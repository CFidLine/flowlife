# StudyFlow – version Android

1. Crée un dépôt GitHub (gratuit) et envoie-y tout le contenu de ce dossier
   (y compris le dossier caché `.github`).
2. Onglet **Actions** > **Build APK** > **Run workflow** (ou simple push).
3. Après ~5 min, ouvre l'exécution terminée, section **Artifacts**,
   télécharge **StudyFlow-apk** (zip contenant app-debug.apk).
4. Sur le téléphone : ouvre l'APK et autorise l'installation depuis cette source.
